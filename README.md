# SigmaOS adler32

This repository is currently a minimal `no_std` component identity scaffold. Its library exposes a `Component` named `SigmaOS-adler32`.

No Adler-32 checksum implementation is present in the current source. Do not use this crate to calculate or verify checksums until that functionality is implemented and validated.

## Build

```sh
cargo check --lib
```
